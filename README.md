## 📌 Overview

This repository contains a collection of **Data Structures and Algorithms (DSA)** programs implemented in **Java**.

It is created for:

- 📚 Learning DSA concepts
- 💻 Coding practice
- 🎯 Technical interview preparation
- 🧠 Logic building

The repository includes topics like **Arrays, 2D Arrays, Sorting Algorithms, Searching Algorithms, and Pattern Printing**.
